# Finance Plugins

Finance-only Claude Code plugin marketplace, split out from [claude-plugins](https://github.com/ryanrodrigues25200525-svg/claude-plugins).

## Plugins

| Plugin | Description |
|---|---|
| `credit` | Credit analysis — banking stress, credit risk, spreads, junk bond monitoring |
| `equity` | Single stock analysis — earnings, valuation, fundamentals, technicals |
| `flows` | Market flows — ETF flows, sector rotation, advance-decline, factor rotation |
| `macro` | Macro research — Fed watch, inflation, rates, recession risk, country reports |
| `portfolio` | Portfolio analysis — factor exposure, concentration risk, stress testing |
| `quant` | Quant & research — factor models, backtesting, strategy building |
| `sector` | Sector analysis — earnings, momentum, valuations, sector reports |
| `sentiment` | Market sentiment — Reddit, WSB, panic scans, narratives, consensus |
| `smart-money` | Smart money tracking — 13F, insiders, whale moves, activist watch |
| `trading` | Trading catalysts — earnings, options, M&A, spin-offs, 8-K alerts |
| `vol` | Volatility — gamma watch, skew monitor, vol crush opportunities |
| `ideas` | Investment ideas — deep value, compounders, contrarian, best ideas |

## Install

```
/plugin marketplace add ryanrodrigues25200525-svg/finance-plugins
```
